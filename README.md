# 🛒 CopySaaS - Générateur de Fiches Produits E-commerce

Un outil SaaS léger, gratuit et responsive qui génère des fiches produits e-commerce optimisées pour le SEO et la conversion grâce à l'intelligence artificielle. 

## ✨ Fonctionnalités

- **Génération IA ultra-rapide** : Propulsé par le modèle Google Gemini API (`gemini-3.8-flash`).
- **Structure E-commerce complète** : Intègre les balises SEO, les accroches, les bénéfices clés, une description détaillée et des templates pour les réseaux sociaux (Meta Ads, Instagram, TikTok).
- **Mise en forme propre** : Rendu automatique et élégant en HTML grâce à la bibliothèque Marked.js.
- **Export facile** : Boutons natifs pour copier le texte dans le presse-papier en un clic ou le télécharger directement au format `.txt`.
- **Système de résilience** : Gestion automatique des pics de trafic de l'API Google (système de retry intégré).
- **Design UI/UX Moderne** : Interface type "Dark Mode" optimisée pour ordinateurs et mobiles.

## 🛠️ Technologies Utilisées

- **Front-end** : HTML5, CSS3, Vanilla JavaScript
- **IA** : API Google Gemini
- **Librairies** : Marked.js (parsing Markdown)
- **Déploiement** : GitHub & Vercel

## 🚀 Comment l'utiliser ?

1. Rendez-vous sur le site web déployé via Vercel.
2. Générez une **clé API Gemini** gratuite depuis [Google AI Studio](https://aistudio.google.com/).
3. Collez votre clé API dans le champ sécurisé de l'application.
4. Décrivez simplement votre produit (ex: *Gourde isotherme en inox 750ml, noir mat*).
5. Cliquez sur **Générer la Fiche Produit**.
6. Copiez ou téléchargez le résultat prêt à être publié sur votre boutique (Shopify, WooCommerce, etc.).
